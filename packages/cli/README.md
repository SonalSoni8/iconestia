# @thinicons/cli

CLI utilities for Thinicons generation and export workflows.

## Commands

```bash
thinicons generate
thinicons generate home
thinicons optimize
thinicons build
thinicons list
thinicons export home --format svg --out ./exports
thinicons export wallet --format jsx
```

## Purpose

- orchestrate core/react generation pipeline
- validate icon names for targeted workflows
- export icon assets/snippets for external usage
